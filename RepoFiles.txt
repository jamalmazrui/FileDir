# RepoFiles.txt -- what the FileDir repository carries.
#
# ONE PATH PER LINE. A trailing slash names a folder wholesale; a wildcard is
# allowed. scripts\tidy writes .gitignore from this as a whitelist -- everything
# ignored, then exactly these allowed -- and scripts\push rewrites it before every
# push, so "git add -A" means "add what the project has named" and never
# "everything in the folder".
#
# NO BINARY IS NAMED HERE. 7-Zip, Ude, Tektosyne, SharpZipLib and the NVDA
# controller client are fetched by the build; FileDir.exe, FileDirScript.dll
# and the installers are built. They live in exec, which LocalFiles.txt names.
