# RepoFiles.txt -- the FileDir files that the setup script does not name.
#
# What belongs in this project is decided in two places and nowhere else:
# FileDir_setup.iss, which lists everything FileDir installs, and this file.
# homerPolicy.py reads both, and the audit and cleanFileDir both read
# homerPolicy, so they cannot form different opinions about the same file.
#
# Two lists follow.
#
# Tracked: files the repository carries that FileDir does not install. A
# clone without them cannot build FileDir.
#
# Local: files that live in this folder without being tracked. They are
# built, generated or written here, so git ignores them, but cleanFileDir
# must leave them alone.
#
# A name in neither list, and absent from FileDir_setup.iss, is not part of
# the project. cleanFileDir moves it into notes\, whatever kind of file it
# is. Nothing is ever deleted.
#
# To ship a file, add a Source line to FileDir_setup.iss.
# To track a file without shipping it, add its name under Tracked.
# To keep a file on disk untracked, add its name under Local.
