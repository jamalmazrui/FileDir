FileDir is free and open source, for Windows, and it aims at one thing: to be the most productive way a screen reader user can manage files and folders. This is a reborn FileDir, more capable than any version before it. Expert AI has been used throughout – to review twenty years of code, modernize it, and build features that were not practical to write before.

FileDir works by marking. Mark any set of items, and one command acts on all of them. With nothing marked, a command acts on the item you are on, so marking is never something you have to do first. Nearly everything below works on a whole folder at once for that reason.

Converting

Choose a file and FileDir offers what that kind of file can become. Word, OpenDocument, EPUB, web pages, Markdown, LaTeX and rich text convert between each other. Older Office files and PDFs become readable text. Audio becomes MP3, FLAC or Ogg; video becomes MP4, Matroska or WebM, or audio alone; pictures convert between the common formats. Each result keeps its name and lands beside the original.

PDFs are read with their structure intact, so headings stay headings and tables stay tables. No Microsoft Office is needed for any of this.

Naming and tidying

One command renames files to what identifies them inside: the title of a document, the caption of a photograph, the song title, the book name. Another finds duplicate files anywhere beneath a folder, compares them byte for byte, and gathers them into a window you can inspect and delete from. A third marks files that are versions of one another, keeping the largest. A fourth renames so an alphabetical list finally reads in order.

Media

Play the marked files, a whole folder, or a play list you copied from somewhere. A play list can even be web addresses, which are fetched as they play. You can also download media from a page, as video or as audio alone.

And there is now a player inside FileDir. Control+Shift+H opens the Homer Player on whatever you are on: the marked files, a play list, or the media links inside a document. A page of podcasts becomes a queue, with the titles the page gave them.

It is a dialog, not a window that takes over. The queue is a list of each track’s name, presenter and length, and it can be sorted by any of them. Buttons move by track and by chapter, jump by an amount you choose from fifteen seconds to an hour, and set speed and volume. Every control has its own Alt key. Playback is on Shift with the arrows, the Page keys, Home and End, which work the same on the number pad and the keys beside it. Scroll Lock plays and pauses from anywhere in the dialog.

Moving anywhere plays what you land on, because listening is how you tell whether you arrived where you meant to. Mark part of a track with F8 and Shift+F8, and Clip to file writes just that part to a file and puts it on the clipboard. Each play list remembers its own speed, volume, jump size and order, and how far each track had played, so playing it again starts where you stopped.

One command shows everything known about a file in a single alphabetical list: its Windows properties, the program that opens it, and the information stored inside it. That means the camera and exposure of a photograph, the artist and album of a song, or the length and codecs of a video.

Working across languages, and asking questions

Translate whole folders of documents into a language you name. Ask an AI a question, or ask about the file you are on, and read the answer in a window you can navigate and copy from.

All of it runs on your own computer. No account, no limit, and nothing is sent anywhere – so you can translate or summarize a document you would never paste into a web page.

For everyone

FileDir leaves window titles and focus changes to your screen reader, which announces them anyway. It speaks only what it alone knows. In describe mode, press any command key to hear what it does, without doing it; every command has a description. When something goes wrong, one command copies the session log to your clipboard, ready to attach to a message.

The documentation comes with FileDir and is meant to be read. There is a user guide, nine tutorials by the kind of work you do, a hotkey reference that lists every command three ways, questions and answers, a history, and a developer guide.

Getting the pieces

Everything optional is a checkbox on the installer’s last page, each saying what it will do, at what version, and how large it is, and each fetched and installed for you. Nothing is a manual download. A component already on your computer is found and offered as an update rather than installed twice, and one copy is shared with EdSharp and HomerScribe.

The document and media tools are ticked, because the conversion features need them. The AI pieces are not: they are several gigabytes, and nobody should download that by failing to notice a checkbox. They buy translation, summarizing and file questions that ask no account and never send a document anywhere.
